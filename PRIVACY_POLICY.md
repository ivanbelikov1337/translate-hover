# Privacy Policy for Hover Translate

**Last updated: November 30, 2025**

## Overview

Hover Translate is a browser extension that provides instant translation of selected text. We are committed to protecting your privacy.

## Data Collection

**We do NOT collect, store, or share any personal data.**

### What the extension accesses:
- **Selected text**: Only the text you manually select on a webpage is processed for translation
- **User preferences**: Your language settings are stored locally in your browser using Chrome's sync storage

### What we DO NOT collect:
- Personal information
- Browsing history
- Cookies
- IP addresses
- Any identifying information

## Third-Party Services

The extension uses **MyMemory Translation API** (api.mymemory.translated.net) to translate text. Only the selected text is sent to this service for translation. Please refer to [MyMemory's Privacy Policy](https://mymemory.translated.net/doc/privacy.php) for their data handling practices.

## Data Storage

All user preferences (target language, enabled/disabled state) are stored locally in your browser using Chrome's built-in sync storage. This data never leaves your browser except through Chrome's own sync mechanism if you have Chrome sync enabled.

## Permissions

The extension requires the following permissions:
- **activeTab**: To detect text selection on the current page
- **storage**: To save your language preferences locally
- **Host permissions (all URLs)**: To allow translation on any website you visit
